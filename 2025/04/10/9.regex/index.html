Common Functions in re Module

re.sub()

  • replace all matches of pattern with repl
  • re.sub(pattern, replace, string)

re.match()

  • atches the pattern oonly at the beginning of string
  • re.match(pattern, string)

re.findAll()

  • finds all occurrences of the pattern in the string
  • re.findall(pattern, string)

re.compile()

  • compiles a regex pattern into a regex object which can be reused
  • re.compile(pattern)

re.search()

  • searches the entire string for the first match
  • re.search(pattern, string)
